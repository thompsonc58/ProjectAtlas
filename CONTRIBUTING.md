# Contributing to Project Atlas

Thank you for contributing.

## Workflow

1.  Read HANDBOOK.md
2.  Follow applicable standards.
3.  Maintain artifact traceability.
4.  Submit changes with clear commit messages.
5.  Update release notes when appropriate.
