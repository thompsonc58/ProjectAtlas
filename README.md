# Atlas Framework
### Engineering Better Learning

> *Transforming real-world expertise into engineered learning experiences.*

## Welcome to Atlas

Atlas is a **Curriculum Engineering Framework** designed to systematically transform real-world knowledge into structured, evidence-based educational experiences.

Rather than viewing curriculum development as a collection of disconnected courses, lessons, and assessments, Atlas approaches education as an engineering discipline—one that can be designed, implemented, evaluated, and continuously improved using repeatable methods and measurable outcomes.

Atlas provides the methodology, standards, governance, and supporting tools needed to engineer curriculum with the same rigor that software engineers apply to building software systems.

---

# Why Atlas?

Educational programs are expected to prepare learners for increasingly complex and rapidly evolving professions.

Yet curriculum development often relies on individual experience, institutional tradition, and disconnected documentation rather than a unified engineering process.

This leads to challenges such as:

- Inconsistent curriculum quality
- Weak alignment between industry and instruction
- Redundant or disconnected learning experiences
- Difficult curriculum maintenance
- Limited traceability between learning outcomes and assessments
- Slow adaptation to technological and workforce changes

Atlas addresses these challenges by introducing **Curriculum Engineering** as a structured methodology for designing educational systems.

---

# The Atlas Method

At the heart of the framework is **The Atlas Method**—a repeatable engineering process for transforming professional expertise into meaningful learning experiences.

The Atlas Method consists of six phases:

1. **Discover** – Analyze the real-world domain.
2. **Engineer** – Translate expertise into competencies and learning outcomes.
3. **Design** – Organize curriculum into programs, courses, modules, and lessons.
4. **Develop** – Create instructional materials, assessments, and learning resources.
5. **Deliver** – Implement instruction and collect evidence of learning.
6. **Improve** – Continuously refine curriculum using assessment data and industry feedback.

Every artifact within Atlas supports one or more phases of this lifecycle.

# The Atlas Framework

The Atlas Framework consists of four integrated components.

## 1. The Atlas Method

The methodology that defines how curriculum is engineered.

---

## 2. The Curriculum Engineering Framework

A collection of engineering standards, specifications, governance documents, templates, and reference materials that implement the Atlas Method.

Examples include:

- Program Specifications
- Course Specifications
- Assessment Standards
- Rubric Standards
- Information Model
- Versioning Strategy
- Documentation Standards

---

## 3. Reference Implementations

Atlas is demonstrated through complete, real-world curriculum implementations.

The primary reference implementation is the **Software Development Associate of Applied Science (AAS)** program.

This implementation demonstrates how the Atlas Method is applied from initial domain analysis through classroom instruction.

---

## 4. Atlas Studio

Atlas Studio is the software platform that supports the Atlas Method.

It provides tooling for curriculum engineering, artifact management, AI-assisted content generation, collaboration, analytics, and continuous improvement.

Atlas Studio automates the methodology—it does not replace it.

# Guiding Principles

Atlas is founded on several core engineering principles.

- Curriculum is engineered—not assembled.
- Learning should be evidence-based.
- Every artifact should have a clear purpose.
- Educational decisions should be traceable.
- Standards create consistency.
- Continuous improvement is part of the engineering lifecycle.
- Curriculum should evolve alongside industry.
