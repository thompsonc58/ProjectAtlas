# Project Atlas

> **Engineering Better Learning**

Project Atlas is a curriculum engineering framework that applies
software engineering principles to the design, development,
documentation, assessment, and continuous improvement of educational
resources.

Rather than treating curriculum as a collection of isolated course
materials, Atlas views every educational artifact as an engineering
asset that can be designed, versioned, reviewed, measured, and
continuously refined.

------------------------------------------------------------------------

## Vision

To create an adaptive, reusable, and industry-aligned curriculum
framework that promotes exceptional student learning while empowering
instructors through effective, efficient, and sustainable educational
resources.

## Mission

To engineer high-quality, version-controlled educational resources using
software engineering principles, evidence-based instructional design,
and continuous improvement practices that prepare students for
successful careers in computing.

------------------------------------------------------------------------

# Why Atlas?

Traditional curriculum often lives in disconnected folders, individual
computers, or learning management systems with little documentation,
limited version history, and inconsistent organization.

Project Atlas was created to solve these challenges by providing a
structured engineering framework for curriculum development.

Atlas emphasizes:

-   Student-centered learning
-   Industry alignment
-   Reusable educational resources
-   Version-controlled curriculum
-   Continuous improvement
-   Professional documentation
-   Instructor collaboration
-   Long-term maintainability

------------------------------------------------------------------------

# Engineering Philosophy

Software evolves.

Curriculum should evolve too.

Project Atlas treats curriculum as an engineering discipline by applying
the same principles that guide professional software development:

-   Plan intentionally.
-   Design before building.
-   Document thoroughly.
-   Review collaboratively.
-   Version continuously.
-   Improve through evidence.

------------------------------------------------------------------------

# Atlas Engineering Principles

1.  Build for Students First
2.  Engineer Before You Build
3.  Everything is Reusable
4.  Every Artifact Has Metadata
5.  Documentation Is Part of the Deliverable
6.  Review Before Release
7.  Measure Everything
8.  Version Everything
9.  Refactor Often
10. Atlas Quality Is Non-Negotiable

------------------------------------------------------------------------

# Atlas Quality Standard

Every Atlas artifact must be:

-   Accurate
-   Complete
-   Professional
-   Documented
-   Maintainable
-   Reusable
-   Version Controlled
-   Industry Relevant
-   Student Focused

If an artifact does not meet these standards, it is not considered
complete.
