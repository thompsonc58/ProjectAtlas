# Atlas Engineering Standard 004

# Versioning Strategy

## Purpose

The Atlas Versioning Strategy establishes a standardized method for
identifying, tracking, and communicating changes to all engineering
artifacts within Project Atlas.

Consistent versioning promotes transparency, traceability,
maintainability, and continuous improvement throughout the curriculum
engineering lifecycle.

## Semantic Versioning

``` text
MAJOR.MINOR.PATCH
```

Example:

``` text
2.3.5
```

### Major

-   Significant curriculum redesign
-   New competency framework
-   Breaking instructional changes

Example:

``` text
1.0.0 → 2.0.0
```

### Minor

-   New module
-   New lab
-   New project
-   Expanded instructor resources

Example:

``` text
1.4.0 → 1.5.0
```

### Patch

-   Grammar corrections
-   Accessibility improvements
-   Formatting updates
-   Updated hyperlinks

Example:

``` text
1.5.2 → 1.5.3
```

All Atlas artifacts shall follow this versioning strategy.

## Closing Statement

Every curriculum artifact represents engineered knowledge.

Versioning preserves the history of that knowledge, supports
collaboration, and provides confidence that every improvement is
intentional, documented, and reproducible.
