# ATLAS-STD-006

# Rubric Standards

## Purpose

The Atlas Rubric Standards establish the engineering principles,
requirements, and quality criteria for developing, implementing,
maintaining, and improving evaluation instruments throughout Project
Atlas.

Rubrics are engineered tools designed to evaluate evidence consistently,
transparently, objectively, and fairly.

Rubrics transform assessment evidence into measurable demonstrations of
competency.

## Scope

This standard applies to every rubric used within Atlas-engineered
curriculum, including:

-   Laboratory Rubrics
-   Project Rubrics
-   Presentation Rubrics
-   Programming Rubrics
-   Documentation Rubrics
-   Research Rubrics
-   Teamwork Rubrics
-   Portfolio Rubrics
-   Capstone Rubrics
-   Practical Demonstrations

## Engineering Philosophy

Within Atlas, a rubric is **not a grading sheet**.

A rubric is an engineered measurement instrument.

Its purpose is to measure observable evidence against predefined
performance criteria.

-   Rubrics evaluate performance---not effort.
-   Rubrics measure evidence---not intentions.

## Guiding Principles

Every Atlas rubric shall be:

-   Objective
-   Observable
-   Measurable
-   Reliable
-   Transparent
-   Aligned
-   Actionable

## Rubric Architecture

Every Atlas rubric consists of four components:

### Evaluation Criteria

Defines what is being measured.

Examples: - Code Quality - Database Design - Problem Solving -
Communication - Testing - Documentation

### Performance Levels

Recommended default:

-   Exemplary
-   Proficient
-   Developing
-   Beginning

### Performance Descriptors

Descriptors shall describe observable behaviors and measurable evidence.

Avoid subjective language such as: - Good - Fair - Poor

Prefer evidence-based descriptions that identify demonstrated
competency.

### Scoring Method

Each rubric shall define:

-   Point values
-   Weighted percentages
-   Pass/Fail criteria
-   Mastery thresholds

## Competency Alignment

Every rubric criterion shall map directly to:

-   Program Competencies
-   Course Outcomes
-   Module Outcomes
-   Learning Objectives
-   Assessment Requirements

No criterion shall exist without documented alignment.

## Rubric Requirements

Every Atlas rubric shall include:

-   Title
-   Atlas ID
-   Version
-   Purpose
-   Assessment Reference
-   Competencies Measured
-   Learning Outcomes
-   Evaluation Criteria
-   Performance Levels
-   Scoring Method
-   Mastery Threshold
-   Feedback Section
-   Revision History

## Evidence-Based Evaluation

Scores shall be assigned only when supported by observable evidence.

Evidence may include:

-   Source Code
-   UML Diagrams
-   Documentation
-   Demonstrations
-   Git History
-   Presentations
-   Reports
-   Database Designs
-   Videos
-   Peer Reviews

Personal opinions shall never determine a score.

## Performance Level Standards

  Level        Description
  ------------ ---------------------------------------------------------
  Exemplary    Demonstrates independent mastery exceeding expectations
  Proficient   Meets all required competencies
  Developing   Demonstrates partial competency requiring improvement
  Beginning    Competency not yet demonstrated

## Quality Assurance

Before release every rubric shall verify:

-   Competency alignment
-   Assessment alignment
-   Observable criteria
-   Objective language
-   Appropriate weighting
-   Clear performance levels
-   Consistent terminology
-   Accessibility compliance

## Continuous Improvement

Rubrics shall be evaluated after implementation using:

-   Student performance trends
-   Instructor feedback
-   Inter-rater reliability
-   Industry relevance
-   Assessment effectiveness
-   Student feedback
-   Curriculum revisions

Rubrics shall follow ATLAS-STD-004 Versioning Strategy.

## Engineering Principles

Atlas rubrics shall:

-   Measure competency rather than completion.
-   Evaluate evidence rather than participation.
-   Encourage professional standards.
-   Support instructional consistency.
-   Produce meaningful feedback.
-   Enable continuous improvement.

## Compliance

All Atlas rubrics shall comply with this standard.

## Closing Statement

Rubrics are the measurement instruments of curriculum engineering.

When designed with consistency, transparency, and evidence-based
principles, they transform subjective grading into objective evaluation
and provide meaningful insight into student competency.

Every Atlas rubric shall measure learning with the same rigor that
engineers apply to measuring system performance.
